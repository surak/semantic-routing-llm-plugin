Apache APISIX AI Gateway plugin

Send every prompt to the right model

ai-decision-router asks a decision model which of your LLMs fits each request, then routes it there, alongside ai-proxy, ai-proxy-multi or any upstream. The routing policy is plain text you can read and review.

Get started View on GitHub

How it works

One extra step in the access phase, between APISIX's AI proxy and the model.

Request arrives

An OpenAI, Responses or Anthropic style request asks for "model": "auto".

Ask the decision model

The prompt and your candidates' routing roles go to a Clef-compatible /v1/systemone endpoint as one choice question.

Pick the winner

The highest-probability candidate wins, unless it is below min_confidence; then the fallback is used.

Route

The body's model is rewritten, or the ai-proxy-multi instance is replaced. Headers report the choice.

Why use it

Readable policy

Each candidate has a routing role written in plain language. No example corpus or embedding model to maintain.

Calibrated choices

The decision model returns a probability per candidate. Set a confidence threshold to fall back when it is unsure.

Fails open

If the decision model is down or slow, requests go to the fallback model instead of failing.

Works with what you have

Use it with ai-proxy, ai-proxy-multi or a plain upstream. No APISIX patch needed.

Client choice respected

With trigger_models, only requests for auto are routed; explicit model names pass through.

Observable

X-AI-Routed-Model, confidence and fallback reason headers, plus $ai_routed_model for loggers.

Configure a route

Add the plugin next to ai-proxy. Describe what each model is for; the decision model does the rest.

plugins:
  ai-decision-router:
    decision:
      model: alias-clef
      auth:
        header:
          Authorization: "Bearer ${{BLABLADOR_API_KEY}}"
    trigger_models: [auto]
    fallback: alias-large
    min_confidence: 0.3
    candidates:
      - name: alias-code
        description: Debugging existing code and reviewing patches.
      - name: alias-mimo-v2.6-pro
        description: Rigorous proofs and deep multi-step reasoning.
      - name: alias-eve
        description: Earth observation and remote sensing.
      - name: alias-large
        description: Broad synthesis with no dominant specialist.
  ai-proxy:
    provider: openai-compatible
    override:
      endpoint: https://api.blablador.fz-juelich.de/v1/chat/completions
